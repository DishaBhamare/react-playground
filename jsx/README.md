# JSX 
## Overview 
JSX is a syntax extension for JavaScript that allows us to write HTML-like markup inside React components. 

## Concepts Covered 
- Single root element 
- Fragments 
- Self-closing tags 
- camelCase attributes 
- JavaScript expressions in JSX 
- Curly braces ## Key Takeaways 
- JSX is transformed into JavaScript. 
- Components must return a single root element. 
- All tags must be closed. 
- Use `className` instead of `class`. 
- Curly braces allow JavaScript expressions inside JSX. 

## Common Mistakes 
- Returning multiple sibling elements without a wrapper. 
- Forgetting to close tags. 
- Using `class` instead of `className`. 
- Writing statements inside curly braces.
