# Conditional Rendering

## Concepts Covered

- if statements
- Ternary operator
- Logical &&
- Conditional JSX

## Key Takeaways

- React uses normal JavaScript for conditions.
- Use `if` for complex logic.
- Use `? :` for two alternatives.
- Use `&&` for optional UI.

## Common Mistakes

- Using `return` outside a component.
- Forgetting curly braces around expressions.
- Rendering different component names by mistake.
