# Props 

## Overview 
Props are used to pass data from a parent component to a child component.

## Concepts Covered 
- Passing props 
- Accessing props 
- Destructuring props 
- props.children 
- Passing functions as props 

## Key Takeaways 
- Props are read-only. 
- Data flows from parent to child. 
- children represents nested content. 
- Functions can be passed through props for communication. 

## Common Mistakes 
- Modifying props directly. 
- Forgetting to pass required props. 
- Using incorrect event names like `Onclick` instead of `onClick`.
