# Responding to Events 

## Concepts Covered 
- Event handlers 
- onClick 
- onChange 
- onSubmit 
- Passing arguments 
- preventDefault 
- Multiple event handlers 
- useState with events 

## Key Takeaways 
- React uses camelCase event names. 
- Pass a function, do not call it immediately. 
- Use arrow functions to pass arguments. 
- Use event.target.value for input values. 
- Use preventDefault for forms. 
- Events are commonly used together with state updates.
