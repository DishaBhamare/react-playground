# useState 

## Concepts Covered 
- Creating state 
- Updating state 
- Functional updates 
- Multiple state variables 
- Batched updates 
- State isolation 

## Key Takeaways 
- `useState` adds state to functional components. 
- State updates trigger re-renders. 
- Functional updates are safer when the next state depends on the previous state. 
- State is private to the component that owns it. 

## Common Mistakes 
- Updating state directly. 
- Expecting state to change immediately. 
- Using the current state value repeatedly in multiple updates.
